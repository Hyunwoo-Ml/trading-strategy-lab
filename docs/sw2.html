02 3년 역사적 백테스트 (구간별 수익률)
현재 등록된 5개 모델의 매매 기준을 과거 약 3년치 실제 시세(M7 + QQQ)에 그대로 적용했다면 분기별로 어떤 수익률이 났을지 재현한 결과이며, SPY·QQQ·TLT를 그냥 매수해 들고만 있었을 경우(buy-and-hold)와도 함께 비교합니다. 위의 실시간 페이퍼 트레이딩 기록과는 완전히 별개의 가상 시뮬레이션이며, SW1 페이지의 워크포워드 검증("수식이 예측력이 있는가")과도 다른 질문 — "실제로 이 규칙대로 거래했다면 얼마를 벌었을까, 그리고 그냥 지수를 사서 들고만 있는 것보다 나았을까" — 에 답합니다. 카드 목록은 좌우로 스크롤하거나 화살표 버튼으로 더 볼 수 있습니다.
