03 Walk-forward 검증 (SW1 퀀트 스코어)
기술 지표 기반 Quant Score(sw1/scoring/integrate.py, 고정 가중치 수식)가 특정 구간에만 우연히 맞았던 게 아니라 여러 독립된 구간에서 꾸준히 순방향 수익률과 상관관계를 보이는지 확인하는 과최적화 방지 검증입니다. 약 2년치 과거 시세를 6개월 롤링 윈도우로 나눠 구간별 Spearman IC(정보계수)를 계산합니다. 뉴스 감성 점수는 과거 시황 아카이브가 없어 이 백테스트에 포함되지 않습니다 — GitHub Actions에서 수동 실행(workflow_dispatch)해야 갱신됩니다.
