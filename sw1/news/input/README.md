# 뉴스/시황 코멘터리 입력 (수동, 누적 로그)

`sw1/news/scorer.py`는 자동 뉴스 피드가 없습니다 (원래 자소서 설계대로,
사용자가 직접 고른 국내 시황/뉴스 코멘터리를 붙여넣는 방식). 이 폴더가
그 수동 입력을 저장하는 곳입니다.

**2026-09-15부터**: 종목별로 매주 통째로 덮어쓰던 `.txt` 방식에서, 날짜가
찍힌 항목을 계속 append하는 `.jsonl` 로그 방식으로 바뀌었습니다. 또한
특정 종목에 묶이지 않는 시황(예: 거시경제/정책 발언)을 위한 별도의 공용
로그도 생겼습니다.

## 파일 구조

```
sw1/news/input/
  AAPL.jsonl           -- AAPL에 대해 직접 입력된 코멘터리 누적 로그
  MSFT.jsonl
  GOOGL.jsonl
  AMZN.jsonl
  NVDA.jsonl
  META.jsonl
  TSLA.jsonl
  market/
    GENERAL.jsonl      -- 특정 종목과 무관한 전체 시장 시황 누적 로그
```

각 줄은 `{"date": "YYYY-MM-DD", "text": "..."}` 형태의 JSON 객체 한 개입니다
(JSON Lines). 예:

```
{"date": "2026-09-15", "text": "실적 발표에서 데이터센터向 매출 가이던스 상향."}
{"date": "2026-09-16", "text": "관련 규제 이슈로 단기 변동성 확대 우려."}
```

## 가장 쉬운 입력 방법: 대시보드의 "뉴스/시황 입력하기" 폼

사람이 직접 이 파일들을 편집할 필요 없이, 라이브 대시보드 상단의
"📰 뉴스/시황 입력하기" 링크(GitHub Issue Form)로 제출하면
`.github/workflows/news-input-intake.yml`이 자동으로 해당 로그 파일에
한 줄을 append하고 커밋합니다. 폼에서 종목 대신 **"전체 시장
(종목무관)"**을 선택하면 `market/GENERAL.jsonl`에 기록됩니다.

파일을 직접 편집하고 싶다면 GitHub 웹 UI나 로컬에서 위 형식대로 한 줄씩
추가한 뒤 커밋해도 됩니다 (반드시 append -- 기존 줄을 지우지 마세요).

## 동작 방식

- `scripts/collect_daily_data.py`가 매 평일 실행될 때마다 종목별 로그와
  `market/GENERAL.jsonl`을 모두 읽어, **최근 14일 윈도우**
  (`sw1.news.log.NEWS_WINDOW_DAYS`, 조정 가능)에 들어오는 항목만 남깁니다.
  윈도우 밖으로 밀려난 오래된 항목은 자동으로 더 이상 채점에 반영되지
  않습니다.
- 종목별 항목 전체와, 그 시점 윈도우 안의 `GENERAL.jsonl` 항목 전체를
  함께 `sw1.news.scorer.score_ticker_if_changed()`에 넘깁니다. **일반
  시황 중 어떤 항목이 이 종목과 관련 있는지는 AI가 프롬프트 안에서 직접
  판단**합니다 (코드에서 키워드로 미리 걸러내지 않습니다) -- 예를 들어
  반도체 수출 규제 뉴스는 관련 반도체 종목에는 반영되고, 무관한 업종
  종목에는 반영되지 않도록 판단됩니다.
- 이번에 모델에게 보여줄 "윈도우 내 전체 항목" 구성이 **지난번 실행과
  똑같으면** (해시 비교) Anthropic API를 다시 호출하지 않고 이전 점수를
  그대로 재사용합니다. 새 항목이 추가되거나, 오래된 항목이 윈도우 밖으로
  밀려나면 "달라졌다"고 보고 다시 채점합니다.
- 반영 시점은 **하루 한 번, 평일 자동 파이프라인 실행 때**뿐입니다 (이슈
  제출 즉시 재채점하지 않음) -- 하루에 여러 건이 입력돼도 API 호출은
  파이프라인당 종목 수만큼으로 예측 가능하게 유지됩니다.
- 스코어링 결과 캐시는 `data/news/cache.json`에 저장됩니다 (윈도우 해시 +
  점수 + 카테고리/출처별 세부 항목).

## 필요 조건

저장소 Settings → Secrets and variables → Actions에 `ANTHROPIC_API_KEY`가
등록되어 있어야 합니다. 키가 없으면 로그에 항목을 추가해도 조용히
건너뛰고 (`news_score=None`) 파이프라인은 정상적으로 계속 돌아갑니다.
