# 가격기준 모델 설정 (사용자 입력)

이 폴더의 JSON 파일 하나가 곧 "모델" 하나입니다. GitHub Pages는 정적 사이트라
화면에서 바로 입력받아 실시간으로 처리할 백엔드가 없기 때문에, 이 폴더의 파일을
직접 편집(또는 새로 추가)하고 커밋하는 것이 사용자 파라미터 입력 방식입니다.
매일 GitHub Actions가 이 폴더를 읽어서 각 모델의 최신 매수1가/매수2가/목표가를
다시 계산합니다.

## 필드 설명

| 필드 | 설명 | 예시 |
|---|---|---|
| `model_name` | 모델 고유 이름 (영문/숫자/언더스코어, 파일명과 다르게 지어도 됨) | `"price_model_1"` |
| `stop_loss_pct` | 손절 퍼센트. **반드시 음수** (예: -0.08 = 진입가 대비 -8%) | `-0.08` |
| `reward_risk_ratio` | 목표가를 산출할 때 쓰는 리스크 배수. `목표가 = 1차매수가 + (1차매수가 - 손절가) * 이 값` | `2.0` |
| `buy2_lookback_days` | 2차 매수가(더 깊은 지지선) 계산에 쓸 최저가 룩백 기간(거래일) | `60` |
| `min_news_score` | (선택) 이 값보다 오늘 뉴스 감성점수가 낮으면 신규 진입(1차/2차 매수) 보류. 생략하면 `null` = 이 게이트 자체를 끔 | `-0.3` |
| `description` | 사람이 읽는 설명 (선택) | 자유 텍스트 |

## 매수1가/매수2가는 어떻게 정해지나요?

사용자가 직접 가격을 입력하지 않고, 아래 기술적 지표를 자동으로 사용합니다
(사용자는 손절%/리스크배수 같은 소수의 파라미터만 정하면 됩니다):

- **매수1가** (얕은 진입): 볼린저밴드 하단(20일)과 50일 이동평균 중, 현재가보다
  낮으면서 더 높은(=더 쉽게 닿는) 쪽
- **매수2가** (깊은 진입): 볼린저밴드 하단과 `buy2_lookback_days`일 최저가 중,
  매수1가보다 더 낮은 쪽
- 지표 데이터가 부족하면(신규 상장 등) 현재가 대비 -3%/매수1가 대비 -5%로 대체

## 뉴스/시황 데이터는 어디서 반영되나요?

`sw1/news/input/{TICKER}.txt`에 수기로 붙여넣은 시황 코멘터리(사용법은 그
폴더의 README 참고)가 매일 자동으로 감성점수(`news_score`, [-1, 1])로
스코어링되어 `data/signals/latest.csv`에 저장됩니다. `min_news_score`를
설정한 모델은 이 점수가 자기 기준보다 낮은 날엔 1차/2차 매수를 보류합니다.
단, 매수1가/매수2가/목표가 자체(기술적 지지선 기반 가격 레벨)는 뉴스로 바뀌지
않습니다 -- 뉴스는 "오늘 새로 진입할지 말지"만 결정하고, SW1이 계산한 가격
레벨 자체는 그대로 유지됩니다.
